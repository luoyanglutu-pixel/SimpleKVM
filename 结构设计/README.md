# 结构设计说明

本目录保留项目现有的SolidWorks装配依赖、外壳零件、STL、3MF打印文件和外观渲染。

重点文件：

- `上壳.SLDPRT`：上壳源文件。
- `后盖.SLDPRT`：后盖源文件。
- `按键2.SLDPRT`：较新的按键源文件。
- `3D_PCB_new_2026-10-21-2.SLDASM`：PCB三维装配参考。
- `原始文件/*.STL`：通用切片输入，但时间早于部分后续SolidWorks修改。
- `打印件/*.3MF`：实际打印候选文件，包含多个迭代版本。
- `外观渲染/`：烟灰半透明外观参考，不代表最终材料、尺寸或表面工艺。

注意：

- 当前没有导出STEP通用交换文件。
- SolidWorks装配包含由EDA/元件库生成的第三方器件模型，这些模型不由本项目重新许可。
- STL、3MF和SolidWorks文件不保证全部来自同一最终修订；打印前应核对PCB孔位、接口高度、按钮行程、螺丝和装配间隙。
- 建议正式发布时增加一份带主要尺寸、公差、螺丝规格和打印参数的装配图。

项目作者自研的外壳、按键和装配设计采用CERN-OHL-P-2.0。
