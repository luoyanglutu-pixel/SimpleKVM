# 结构与打印说明

## 文件选择

- 需要继续修改结构时，优先使用SolidWorks源文件。
- 只需要切片打印时，可使用`结构设计/打印件`中的3MF。
- `结构设计/原始文件`中的STL时间较早，使用前应与最新SolidWorks零件对比。

## 打印前必检

1. PCB外形、固定孔位置和板厚。
2. 四个电脑侧USB-C接口的开口位置。
3. 三个USB-A和一个USB-C输出口的开口与插拔空间。
4. 四个按键的行程、回弹和不同时按下的间距。
5. LED高度和可视角度。
6. WCH-Link下载口是否需要在外壳上预留维修空间。
7. 上下壳固定方式、螺丝长度和防止顶到PCB的间隙。

项目尚未记录统一的材料、层高、支撑、壁厚和公差参数。不同打印机和材料收缩率不同，建议先打印局部接口/按键测试件，再打印完整外壳。
