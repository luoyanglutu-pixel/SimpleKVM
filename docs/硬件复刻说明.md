# 硬件复刻说明

## 1. 设计范围

SimpleKVM通过CH444G选择四台电脑中的一路USB D+/D−，再送入CH334P四口Hub。CH32V003不处理USB协议，只负责按键、LED和CH444G的EN#/IN0/IN1控制。

四路电脑VBUS分别通过自恢复保险丝和CH213K后合并到SYS_5V。正常按键切换只改变数据通路，不主动切断键鼠电源。

## 2. 电脑与器件对应

| 电脑口 | 保险丝 | 防反灌器件 | CH444G数据支路 |
| --- | --- | --- | --- |
| PC1 / USB1 | F1 | U2 | S1A/S1B |
| PC2 / USB2 | F2 | U1 | S2A/S2B |
| PC3 / USB3 | F3 | U3 | S3A/S3B |
| PC4 / USB4 | F4 | U4 | S4A/S4B |

PC1与PC2的CH213K位号顺序是U2、U1，不要按数字直觉装反。

## 3. 下载接口

H1实际定义：

| H1 | 信号 | MCU |
| --- | --- | --- |
| 1 | SWIO | PD1 / 18脚 |
| 2 | NRST | PD7 / 4脚 |
| 3 | GND | GND |

目标板自行5V供电时，不连接WCH-LinkE的3.3V或5V输出，也不需要SWCLK。

## 4. 首次上电

1. 不接电脑和键鼠，测SYS_5V对GND是否存在稳定低阻短路。
2. 使用带限流的5V实验电源，从低电流限制开始供电。
3. 检查SYS_5V、U6.15 V5、U6.16 VDD33、U8.9 VDD和KEY1.16 VCC。
4. 确认无异常发热后再接电脑。
5. 先烧录bringup固件验证四键四灯，再烧录dev固件验证USB。

## 5. 可编辑工程与生产资料缺口

当前包提供`硬件设计/ProPrj_SimpleKVM_2026-10-29.epro2`，由嘉立创EDA专业版4.1.78导出，内部包含3页原理图和1块PCB。打开后应先确认工程能正常加载，并将PCB、同日期原理图PDF和BOM相互核对，再重新执行ERC/DRC。当前没有同版本ENET网表，历史连接清单不能代替本次检查。

当前仍没有可直接交付工厂的生产文件。下单前需要从工程重新导出并复核：

- Gerber与NC Drill；
- 板框、叠层、铜厚和成品厚度；
- BOM与贴片坐标；
- 顶底层装配图；
- USB差分阻抗要求和生产备注。

## 6. 自恢复保险丝与回流焊

5块样机此前有3块异常，最终均已修复。已确认故障与回流焊后F1～F4所用0603自恢复保险丝损坏、冷态阻值显著增大有关，更换保险丝后功能恢复。

自恢复保险丝并非原则上不能回流焊。复刻时应核对准确料号和批次的回流曲线，记录实际峰值温度、液相线以上时间和重复回流/热风返修次数。首次上电前逐个测量F1～F4冷态阻值，并测量VBUS两侧压降；阻值异常时先更换保险丝，不要直接用导线长期短接保护器件。
