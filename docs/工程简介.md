# SimpleKVM 四路USB键鼠切换器

## 项目简介

SimpleKVM是一款让4台电脑共用一套USB键盘和鼠标的桌面切换器，适合多电脑办公、软件调试、设备维护和测试台等需要频繁切换控制对象的场景。

设备提供4个电脑侧USB-C接口，以及3个USB-A、1个USB-C下游接口。用户按下1～4号实体按键即可选择目标电脑，对应LED显示当前通道。切换过程不需要在电脑上安装驱动，也不依赖控制软件。

本项目只切换USB数据，不包含HDMI、DP等视频切换功能。普通有线键盘、鼠标，以及带USB接收器的2.4G或双模键鼠可以使用；纯蓝牙键鼠不能直接连接本设备。

## 工作原理

四台电脑的USB D+/D−首先进入CH444G双路四选一模拟开关。CH32V003F4P6根据按键选择控制CH444G，先断开当前USB通路，再修改选择信号，最后接通新通道，避免切换瞬间同时连接两台电脑。

CH444G选出的数据通路进入CH334P四口USB Hub，再分配到3个USB-A和1个USB-C输出口。切换后，目标电脑会重新枚举键盘、鼠标或USB接收器，通常需要短暂等待。

四路电脑VBUS分别经过0603自恢复保险丝和CH213K防反灌器件后合并为SYS_5V。按键切换只改变USB数据通路，不主动关闭键盘、鼠标和Hub的公共供电，因此正常切换时外设不会因换电脑而直接断电。

## 软硬件组成

| 功能 | 方案 |
| --- | --- |
| 控制MCU | CH32V003F4P6 |
| 四路USB数据选择 | CH444G |
| 四口USB Hub | CH334P |
| 四路VBUS防反灌 | CH213K × 4 |
| 输入保护 | 0603自恢复保险丝 × 4 |
| 人机交互 | 4个实体按键 + 4个通道LED |
| 固件 | v0.1.1，上电默认PC4/LED4 |
| 下载方式 | WCH-LinkE，SWIO单线下载 |

固件实现四键消抖、多键锁定、长按不连发、先断后接、同通道重复按键保持连接，以及开发版/发布版看门狗策略。MCU不运行USB协议栈，USB枚举和数据转发由CH334P及硬件数据通路完成。

## 使用方法

1. 使用支持数据传输的USB-C线，将PC1～PC4连接到电脑。
2. 将键盘、鼠标或USB接收器接入任意下游输出口。
3. 按1～4号按键选择目标电脑。
4. 对应LED点亮后，等待电脑完成USB重新枚举即可使用。

## 当前验证状态

- 5块样机现均已修复并恢复基本功能。
- 此前3块异常已确认与回流焊后0603自恢复保险丝损坏、冷态阻值异常有关，更换保险丝后恢复。
- v0.1.1固件已通过23项主机端逻辑测试、随机状态测试和三种配置交叉编译。
- 历史`2026-10-21-2`导出网表与固件GPIO映射检查通过；当前10月29日工程未附同版本ENET网表。
- 已提供嘉立创EDA专业版`.epro2`可编辑工程，内部包含3页原理图和1块PCB。

自恢复保险丝正常情况下应能承受符合规格的回流焊。本次故障提示仍需核对准确料号、批次、炉温曲线、峰值温度、液相线以上时间和重复回流次数；不能据此推断所有PTC均不适合回流焊。
