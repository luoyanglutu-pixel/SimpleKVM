# 嘉立创开源社区发布文案

## 项目标题

SimpleKVM：四台电脑共用一套键盘鼠标的USB切换器

## 一句话简介

基于CH444G、CH334P和CH32V003的四进四出USB键鼠切换器，支持实体按键切换、通道指示灯和USB-A/USB-C下游接口。

## 项目介绍

SimpleKVM是一款让4台电脑共用一套USB键盘和鼠标的桌面切换器，适合多电脑办公、软件调试、设备维护和测试台等需要频繁切换控制对象的场景。

设备提供4个电脑侧USB-C接口，以及3个USB-A、1个USB-C下游接口。CH444G从四路USB数据中选择一路送入CH334P四口Hub；CH32V003F4P6扫描四个实体按键、驱动四个通道LED，并以先断后接的方式切换数据通路。使用时无需安装驱动或电脑端控制软件。

当前v0.1.1固件上电默认选择PC4，LED4亮。切换后电脑需要重新识别键盘、鼠标或USB接收器，通常需要数秒。

本项目只切换USB数据，不切换视频；纯蓝牙键鼠不能直接连接，带USB接收器的无线键鼠可以使用。

完整的工作原理、软硬件组成、使用方法和验证边界见[工程简介](工程简介.md)。

## 主要特点

- 四台电脑手动切换；
- 三个USB-A和一个USB-C输出；
- 四个独立按键和状态指示灯；
- CH32V003开源固件；
- SolidWorks、STL和3MF外壳资料；
- 低成本电源合路和防反灌设计。

## 当前状态

这是功能样机，不是量产成熟方案。5块样机现均已修复并恢复功能；此前3块异常已确认与回流焊后0603自恢复保险丝损坏、阻值异常有关，更换保险丝后恢复。开源包已提供嘉立创EDA专业版可编辑工程、原理图PDF、BOM、固件和结构文件，但同版本ENET网表、Gerber、钻孔和贴片坐标尚未补齐。请复刻者先阅读README中的回流焊注意事项和首次上电检查。
