# 发布前检查清单

## 必须确认

- [ ] 补充发布者名称或网名，并确认版权归属。
- [ ] 确认硬件/结构使用CERN-OHL-P-2.0，固件使用MIT，文档使用CC BY-SA 4.0。
- [x] 提供实际投板的嘉立创EDA专业版原理图/PCB工程。
- [ ] 从实际投板工程导出并复核Gerber、NC Drill和贴片坐标。
- [ ] 确认PCB、原理图、BOM、贴片坐标属于同一版本。
- [ ] 确认v0.1.1实板上电确实选择PC4/LED4。
- [ ] 记录四个实体按键、LED和电脑口的实际对应关系。
- [ ] 完成至少一块板的四电脑、四输出、正反插和热插拔验证。
- [x] 修复三块异常样机并记录根因：回流焊后0603自恢复保险丝损坏、阻值异常。
- [ ] 核对保险丝准确料号、批次和回流温度曲线，形成可重复的工艺记录。
- [ ] 确认产品照片、渲染图和CAD文件有权公开。
- [ ] 检查所有压缩包中不含本机绝对路径、账号、密钥或临时文件。

## 建议补充

- [ ] STEP通用结构文件。
- [ ] 结构尺寸图、螺丝规格和打印参数。
- [ ] PCB顶底层装配图。
- [ ] 空载/键鼠负载电流、各路压降和温升记录。
- [ ] USB枚举测试表和已验证键鼠/接收器列表。
- [ ] 故障排查照片和关键测点图。
- [ ] GitHub Issues模板和贡献指南。

## 发布后

- [ ] 为硬件缺失项建立Issue并固定在README。
- [ ] 每次改硬件同时更新原理图、PCB、BOM、结构模型和固件引脚校验。
- [ ] 每个Release保留对应HEX、源码、硬件修订号和SHA-256。
