## 2. 自恢复保险丝工艺要求

5块样机此前有3块异常，最终确认与回流焊后F1～F4阻值异常有关，更换保险丝后恢复。当前BOM仍采用`JK-SMD0603-050L-6`，因此后续生产需要：

1. 记录保险丝准确批次和供货来源。
2. 按厂商允许的回流曲线控制峰值温度、液相线以上时间和回流次数。
3. 避免对保险丝反复热风返修。
4. 上电前逐只测量F1～F4冷态阻值，并比较4路一致性。
5. 带载时测量保险丝两端和CH213K两端压降。

自恢复保险丝并非原则上不能回流焊。若再次出现批量阻值漂移，应暂停使用该批次并做炉温曲线和来料复核，不要长期用导线短接保险丝代替整改。

## 3. 上电前检查

1. 在EDA中执行ERC和PCB DRC，确认当前原理图、PCB和BOM是同一版本。
2. 检查SYS_5V对GND没有低阻短路，HUB_VDD33没有短接到5V，4路电脑VBUS没有绕过CH213K直接并联。
3. 测量F1～F4冷态阻值及4路一致性，检查CH213K、U6、U8、KEY1和USB接口方向。
4. 首次使用限流5V电源从单路输入供电，记录空载电流和SYS_5V、U6.V5、HUB_VDD33。
5. 先烧录bringup固件检查4键4灯，再烧录dev固件验证USB数据切换。
6. 逐路供电并测量未供电电脑端的反灌电压和电流；不要用普通电流表直接短接带电VBUS。

## 4. 实板测试矩阵

| 项目 | 方法 | 通过条件 |
| --- | --- | --- |
| 4路供电 | 每次只接一路电脑或限流5V，记录F前后、CH213K前后和SYS_5V | 4路均能稳定启动，压降和温升无异常 |
| 低压带载 | 输入降到实际主机端口下限，连接目标键鼠负载 | Hub、MCU和外设稳定工作，不只验证MCU亮灯 |
| 热插拔 | 空载和带键鼠分别插拔每路输入 | 无异常复位、过流保护或保险丝阻值漂移 |
| 12种切换 | 每台电脑切到其余3台，键盘鼠标同时连接 | 只在目标电脑枚举，按键不连发，无中间误通 |
| 4个下游口 | USB8正反插；USB5～USB8逐口及同时连接低功耗设备 | 4个Hub端口均能识别，Type-C两个方向一致 |
| 睡眠和关机 | 测各电脑睡眠、唤醒、关机待机供电 | 记录供电来源和数据目标，不把有5V等同于系统在线 |
| 反灌与误接 | 限流台架检查未供电输入和USB8 VBUS | 无不可接受反向电流；不直接用电脑端口做对冲测试 |
| 长期运行 | 多电脑、多线材循环切换并运行键鼠 | 无死机、异常复位和通道错乱 |

## 5. 交付边界

5块样机当前均已恢复基本功能，但这不等于USB认证、ESD/EMC、全部电脑和外设兼容性或批量一致性通过。当前目录没有Gerber、NC Drill、贴片坐标、装配图和10月29日同版本ENET网表。

固件测试入口见[10_软件方案.md](10_软件方案.md)。PCB生产文件导出前还需检查板厂叠层、USB差分阻抗、封装方向、插件孔径、外壳配合和装配工艺。
