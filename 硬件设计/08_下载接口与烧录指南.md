# CH32V003下载接口与烧录指南

更新日期：2026-10-29。适用当前V1.0硬件基线，CH32V003F4P6（TSSOP20）、板上公共5V供电。10月29日原理图保持PD1/SWIO、PD7/NRST和H1线序不变。

## 1. 单线下载的准确含义

只占用一个MCU通信IO：PD1/SWIO（18脚）。不需要SWCLK，但MCU必须有供电，且下载器必须与板子共地。普通下载可以不连接NRST，保留该焊盘有助于硬件复位和故障恢复。

## 2. 下载器与软件

推荐购买WCH-LinkE，确认支持CH32V003及RISC-V单线下载；不要把旧WCH-Link或仅支持ARM的WCH-DAPLink当作等价型号。ST-Link、J-Link V8及普通USB转串口模块不能按本方案直接替代WCH-LinkE。JTAG/SWD接口并不等于CH32V003的SDI协议。

- [原厂WCH-Link产品页](https://www.wch.cn/products/wch-link)：核对WCH-LinkE型号及资料。
- [WCH-Link使用手册V2.4](https://www.wch.cn/uploads/file/20250124/1737704462135866.pdf)：第4页列出CH32V003使用PD1、无SWCLK；第2页模式切换；第10页及后续介绍Utility下载和恢复。
- [WCH-LinkUtility下载](https://www.wch.cn/downloads/WCH-LinkUtility_ZIP.html)：已有HEX/BIN时使用。
- [MounRiver Studio](https://mounriver.com/)：开发、编译、下载和调试固件。

当前文件夹已有[10_软件方案.md](10_软件方案.md)，可直接烧录的HEX/BIN位于[软件发布目录](../软件设计/releases/v0.1.1/README.md)。项目已完成WCH-LinkE实际连接和下载操作；预编译文件的逻辑测试、构建状态及尚未完成的版本级实板项目以软件目录记录为准。

## 3. 推荐接线：板子自行5V供电

| WCH-LinkE端 | 板子端 | 是否连接 |
| --- | --- | --- |
| SWDIO/TMS（按下载器丝印） | PD1/SWIO，MCU18脚 | 必接 |
| GND | 板上GND，通到MCU7脚VSS | 必接 |
| RST（按实际下载器丝印与版本） | PD7/NRST，MCU4脚 | 普通烧录可不接；恢复时可接 |
| SWCLK/TCK | 无 | CH32V003单线下载不接 |
| 3V3 | 无 | 板子已5V供电时不接 |
| 5V | 无 | 板子已5V供电时不接 |
| TX/RX | 无 | 烧录不需要，本版PD5/PD6已分配按键 |

WCH-LinkE的3V3/5V是电源输出，不是必须连接的目标电压检测输入。前版J8的“5V参考”应理解为板上电源测试点，不得据此直接连接下载器电源输出。正常用一根电脑USB线给板子供电，再接GND与SWDIO即可；首次台架也可用合适的限流5V电源。

若需要下载器给板子供电，应另行确认其可供电流、目标电平和整板负载，断开其它供电来源，并通过明确的供电接入/隔离方式操作；不能将下载器电源与在工作的板上5V直接并联。本指南优先使用板子自行供电，避免下载器承担Hub及键鼠负载。

## 4. 原理图怎么留接口

极简正常烧录仅需两个信号焊盘：SWIO、GND。建议再留一个NRST测试焊盘，板上SYS_5V本来已有电源测试点，无须为其增加必插线。

当前实际接口为H1：**1=SWIO、2=NRST、3=GND**。旧草稿J8的“1=GND、2=SWIO、3=NRST”顺序作废。H1不是WCH-LinkE排针的物理顺序，必须按网络名转接，不能直接按位置对插。可采用弹簧针或临时引线。

SWIO直接连接PD1，不额外加大电容或挂LED；NRST保持原有10kΩ上拉SYS_5V，不改作按键。固件开发期保留PD1调试功能与PD7复位功能。

## 5. WCH-LinkUtility烧录步骤

1. 将WCH-LinkE插入电脑，安装工具包配套驱动（若系统需要），打开Utility。
2. 查询Link模式并切到RISC-V。按原厂手册使用Active WCH-Link Mode的Get/Set，具体界面随版本可能变化。
3. 给板子5V供电，接好GND与SWDIO，选择RISC-V、CH32V00X系列/CH32V003目标，连接并读取芯片信息。
4. 添加编译完成的HEX或BIN。普通用户程序目标为Code Flash，BIN起始地址为0x08000000；HEX按其有效编译地址处理，不误选0x1FFFF000系统存储区。
5. 选择编程、校验、复位运行并执行下载；新空片一般不需要改用户选择字。确认工具报告校验成功，再按四个按键验证对应LED与USB通道。

自己编写固件时，用MounRiver Studio选CH32V003工程、编译生成固件，再从IDE下载或交给Utility。

## 6. 连不上时

先查板上VDD、共地、PD1脚号、模式和线序；使用短引线，可将下载速度调低。不要因下载失败就把3.3V输出接到5V板上。

若用户程序占用SWIO、立即睡眠等导致连接困难，可按官方工具的硬件复位或断电恢复流程处理：使用NRST恢复需接RST；使用工具自动断电恢复需由工具真正控制目标供电。当前板子自行供电时，工具关闭自己的电源输出并不会切断板上USB供电。

本项目已经使用WCH-LinkE完成实板识别和烧录。5块样机现均恢复基本功能；此前异常与回流焊后自恢复保险丝阻值异常有关，不属于下载接口故障。

## 7. 本版不使用串口IAP

PD5/PD6已接SW3/SW4，不能直接把USB转串口的TX/RX接上去烧录。若另做UART IAP，需要先通过SDI预置/配置相应IAP程序、定义入口及引脚冲突处理，并使用配套协议工具；普通空片串口下载不属于本版验收流程。当前正常更新始终走H1和WCH-LinkE。
