# 四电脑键鼠共享器硬件方案

版本V1.0；更新日期2026-10-29。当前基线为`ProPrj_SimpleKVM_2026-10-29.epro2`、`SCH_SCH_new_2026-10-29.pdf`和`BOM_SimpleKVM_new_SCH_new_2026-10-29.xlsx`。

## 1. 系统组成

每台电脑通过一根USB-C数据线连接本板。CH444G从4台电脑中选择一路USB数据送入CH334P Hub，Hub提供3个USB-A和1个USB-C下游接口。CH32V003F4P6读取4个按键、驱动4个LED，并控制CH444G的EN#、IN1和IN0。

```text
电脑1 USB1 ─┐
电脑2 USB2 ─┤   KEY1 CH444G      U6 CH334P      USB8 Type-C
电脑3 USB3 ─┼── USB数据四选一 ── USB Hub ──── USB5 Type-A
电脑4 USB4 ─┘                                  USB6 Type-A
                  ↑ EN#、IN1、IN0              USB7 Type-A
             U8 CH32V003F4P6
                四按键、四LED

USB1 VBUS → F1 → U2 CH213K ─┐
USB2 VBUS → F2 → U1 CH213K ─┤
USB3 VBUS → F3 → U3 CH213K ─┼→ SYS_5V → Hub、MUX、MCU、四个下游口
USB4 VBUS → F4 → U4 CH213K ─┘
```

电脑1与电脑2的CH213K位号顺序为U2、U1；电脑3、4对应U3、U4。CH444G的位号仍为KEY1，文档按现有工程保持该编号。

## 2. 功能边界

- 同一时刻只有一台电脑连接Hub的数据通路。切换后Hub和外设会在新电脑重新枚举。
- MCU不处理USB协议，不运行USB Host或HID协议栈，也不支持键盘热键切换。
- 支持普通有线键鼠和带USB接收器的无线键鼠。纯蓝牙键鼠不能直接与本板配对。
- 本项目不切换HDMI、DP等视频信号。
- USB8是常供电的下游Type-C口，使用两个56kΩ Rp电阻。当前没有CC接入检测、VBUS受控开关或输出防反灌，不能作为通用充电口或双角色Type-C口宣传。
- 无电脑在线检测和VBUS检测。LED只表示MCU选择的通道，不表示电脑已开机或USB枚举成功。

## 3. 电源方案

四路电脑VBUS分别经过F1～F4和CH213K后合并到SYS_5V，不能直接短接四台电脑的VBUS。正常按键切换只改变USB数据通路，不主动切断Hub和键鼠供电；只要至少一路供电稳定，切换时外设通常不会掉电。

| 电脑口 | 保险丝 | 防反灌器件 | 输入侧10uF |
| --- | --- | --- | --- |
| USB1 / 电脑1 | F1 | U2 | C10 |
| USB2 / 电脑2 | F2 | U1 | C5 |
| USB3 / 电脑3 | F3 | U3 | C7 |
| USB4 / 电脑4 | F4 | U4 | C9 |

F1～F4当前料号为`JK-SMD0603-050L-6`，立创商城编号C5224376。5块样机此前有3块在回流焊后出现保险丝阻值异常，更换后恢复。该现象应按料号、批次和回流工艺继续验证，不能据此断言所有PTC都不能回流焊；上电前应逐只测量冷态阻值和带载压降。

SYS_5V侧默认装配的主要电容为C1、C4、C14共30uF，C2、C13、C16共3uF，以及C3、C11共200nF，标称合计33.2uF。C12=1uF接CH334P的HUB_VDD33。C15=10uF默认不装。四路输入侧C10、C5、C7、C9各10uF。

U8和KEY1直接使用SYS_5V。U6.16的HUB_VDD33是CH334P内部LDO输出，只接C12去耦，不给MCU供电。数据链路未装ESD器件，也未用普通串联电阻冒充ESD保护。
