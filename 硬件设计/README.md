# 硬件资料说明

当前发布基线更新于2026-10-29，目录保持扁平结构：

- `ProPrj_SimpleKVM_2026-10-29.epro2`：嘉立创EDA专业版4.1.78可编辑工程，包含3页原理图和1块PCB。
- `SCH_SCH_new_2026-10-29.pdf`：三页原理图PDF。
- `BOM_SimpleKVM_new_SCH_new_2026-10-29.xlsx`：与当前原理图一并导出的BOM。

当前方案为CH32V003F4P6 + CH444G + CH334P，提供4个电脑侧USB-C输入、3个USB-A下游口和1个USB-C下游口。BOM共有20个物料行、60个默认装配器件。原理图共67个位号，其中R1～R4、C6、C8、C15共7项默认不装。

当前PDF和BOM未附同版本ENET网表。`04_引脚连接清单.json`以及11～13号审查报告记录的是2026-10-20至21日的历史基线，只用于追溯；当前关键GPIO和USB映射已按10月29日PDF重新目视核对，但没有用新版网表重新执行自动连接检查。

现有工程仍未提供Gerber、NC Drill、贴片坐标和装配图。复刻前应在嘉立创EDA专业版中打开`.epro2`，执行ERC/DRC，核对封装、板框、差分线、铺铜和版本，再自行导出生产文件。

5块样机现均已恢复基本功能。此前3块异常与回流焊后F1～F4所用`JK-SMD0603-050L-6`自恢复保险丝损坏、阻值异常有关，更换后恢复。正式复刻必须核对保险丝批次和厂商回流曲线，并在上电前测量每只保险丝冷态阻值。

硬件设计采用CERN-OHL-P-2.0；第三方器件模型和数据手册保留各自原有权利。
